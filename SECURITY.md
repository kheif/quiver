# Security

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub: open the [Security tab](https://github.com/kheif/quiver/security) of this repository and choose **Report a vulnerability**.

Include the Quiver version (`quiver --version`), your system, and the steps to reproduce. You will get an answer within a week.

## Supported versions

Fixes go into the latest release only.

## What Quiver trusts

Skills give instructions to your assistant and can include scripts. Quiver serves skills from your library and from the sources you added; it does not check what they say. Add only sources you trust, and read what `quiver update` reports as changed.
